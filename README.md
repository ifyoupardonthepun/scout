# Role Fit Board

A private, resume-aware job search board that helps users discover, compare, and track roles in one place.

## What it does

- Finds roles from public job boards
- Shows match scores based on your saved resume
- Lets you filter, sort, save, apply, or skip roles
- Tracks applications from review through submission
- Supports light and dark mode
- Works on desktop and mobile browsers

## Privacy

Your board is protected with a secure passphrase.

- Resume files are processed in the browser
- Private profile details are encrypted before they are stored
- The public site does not contain resumes, passwords, API keys, or personal job-search data
- Job listings come from public employer job boards
- This public repo only contains the basic site build; all the fun stuff is protected behind a secondary private repo. (Planning to release a version  in the future that doesn't consume AI tokens and can be run locally using classic NLP and ML techniques)

## Using the board

1. Open the board link.
2. Complete your profile and upload or paste your resume.
3. Review roles in **Jobs**.
4. Use **Apply** to move a role into your application workflow.
5. Check **Applications** to track progress.

## Notes

Match scores help with prioritisation, not a guarantee of fit or eligibility. Always review a posting before applying.

Some roles may be shown as unscored when the employer no longer provides readable posting text or the role has closed.
